Acesso Remoto via Tailscale

Controle seu projetor de qualquer lugar do mundo (4G, 5G ou Wi-Fi externo) com segurança ponto a ponto (WireGuard).

Status no Projetor: Toque em verificar
1

No Projetor: Instalar & Conectar

Dispositivo Alvo

Instale o Tailscale no sistema Android do projetor para integrá-lo à sua rede mesh privada e segura:

  • Opção A (Via APK / Pen Drive): Baixe o APK oficial do Tailscale (versão Android TV / Android) e instale via pen drive ou navegador do projetor.
  • Opção B (Via Comando ADB no PC): Com o projetor conectado na mesma rede Wi-Fi, instale diretamente via terminal:
    adb install tailscale.apk
  • Login no App: Abra o aplicativo Tailscale no projetor, selecione sua conta (Google, Microsoft, GitHub ou Apple) e ative a chave de conexão (toggle Active).
  • Identificar o IP 100.x: Localize o endereço fixo do projetor na faixa 100.x.x.x (por exemplo: 100.85.12.34).
2

No Celular: Conectar Mesma Conta

Seu Smartphone

Instale o aplicativo Tailscale no smartphone que você usará como controle remoto:

  • Baixe o aplicativo Tailscale na Google Play Store (Android) ou na App Store (iPhone / iPad).
  • Faça login utilizando exatamente a mesma conta configurada no projetor no Passo 1.
  • Ative a chave VPN dentro do aplicativo Tailscale do celular.
  • Pronto! A partir de agora, seu celular e o projetor compartilham uma rota criptografada direta (WireGuard), funcionando normalmente na rede móvel (4G/5G) ou em qualquer rede Wi-Fi externa.
3

No Painel Web: Reconexão Dinâmica

Acesso Universal

Vincule o IP Tailscale do projetor para comandá-lo de qualquer navegador:

  • Abra este painel web no celular através da URL do Cloudflare Pages.
  • No alerta "Offline / Desconectado" exibido no topo (ou clicando no ícone ⚙️ Configurações), digite o IP Tailscale anotado (ex: 100.85.12.34).
  • Toque no botão Reconectar. O indicador mudará instantaneamente para Online!
  • O endereço fica salvo automaticamente no localStorage do navegador, garantindo reconexão imediata nas próximas visitas.
